Hive documentation

The desktop AI that does things — chat, research, code, and a buddy that clicks your PC for you.

Overview

Hive is a Windows desktop workspace. One window holds a chat column with cited answers, a code canvas, a roster of agent bots, HiveBox, and a system-wide buddy — an orange companion that trails your cursor and pops a notch island with Ctrl + Shift + J.

Local-first. Chats, settings, and transcripts live on your machine.

Access

Hive is an invite-only Windows preview. Join the waitlist on this site. When a spot opens, we email you. There is no public installer on this page. Product updates and upcoming features land in the Hive.ai community.

Chat & search

Your messages render as right-aligned bubbles; assistant replies are full-width. Words like search, latest, news, who is, lookup trip the web pipeline. Answers arrive with Verified Sources cards: domain, title, snippet, links. Empty-state chips: Research the web · Write code · Control my PC.

The mode pill in the title bar is Fast, Auto, Heavy, or Max — Hive picks the model for you.

Buddy

  • Messages — every assistant reply carries the orange house avatar.
  • Cursor — trails the mouse across screens with spring physics and a click-pop.
  • System window — click-through, always on top, hides when Hive hides.

Recolor it in Settings → Buddy Color: Orange, Ink, Ghost, Cobalt, Amber.

Notch & hotkeys

Press Ctrl + Shift + J anywhere — even with Hive minimized. A black pill pops at the top of your screen and opens into the Buddy panel. Dictate with the mic, type a question, or run slash commands. Esc dismisses. Tray → Ask Hive opens the same notch.

PC control

Operator waits for Allow / Deny before touching the PC. Destructive shell is refused. Every action lands in the overlay audit log.

CommandDoes
/open Launches apps or URLs
/run Runs a shell command, returns output
/click Moves the cursor and left-clicks
/type Types into the focused window

Swarm & bots

Scout, Hive, and Pulse start together on one message. Critic only runs after Hive answers. Sentry watches tool calls and rewrites fake citations or destructive commands. A swarm strip appears when two or more agents overlap.

Command palette

Ctrl + K opens the palette: new chat, group, Buddy, canvas, settings, workers, notch.

HiveBox

The right-side panel is a live view of HiveBox: a tiny disk, logs, and concurrent Scout / Hive / Pulse jobs. Toggle it in the title bar. Commands: ls, cat, echo, pwd, uname.

FAQ

Windows only?

Yes, today — the buddy click/type engine is Windows-native.

Is it free?

The preview is invite-only. Join the waitlist — we’ll write when a spot opens.

Where is my data?

On your machine: chats and settings in local storage. The website keeps only auth + profile rows.

Voice calling?

Coming soon. Dictation and spoken answers work now.

The buddy vanished!

It hides with the app by design — show Hive and it returns.
