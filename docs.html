Hive documentation

The desktop AI that does things — chat, research, code, and a buddy that clicks your PC for you.

Overview

Hive is a Windows desktop workspace (Electron + React) with a true-black, Grok-grade interface. One window holds everything: a chat column with cited answers, a code canvas, a roster of agent bots, and a system-wide buddy — an orange companion that trails your cursor and pops a notch island anywhere with Ctrl + Shift + J.

Local-first. Chats, settings, and transcripts live on your machine. The only network calls are your model provider and, on the website, Supabase auth.

Quickstart

  1. Clone the repo and install: npm install
  2. Daily driving: npm run dev · Production build: npm run build · Installer: npm run dist:win
  3. Open Settings → Models and paste your OpenRouter key (or use the default free models).
  4. Enable Hive Buddy at Cursor in Settings → General.

Chat & search

Your messages render as right-aligned bubbles; assistant replies are plain full-width text. Ask anything — or trigger the search pipeline with words like search, latest, news, who is, lookup.

Web answers arrive with Verified Sources cards: domain chip, title, snippet, blue links. Suggestion chips on the empty state (Research the web · Write code · Control my PC) send one-tap starter prompts.

Tip. The mode pill in the title bar is Fast, Auto, Heavy, or Max — Hive picks the model for you.

Buddy

The orange house avatar (a live morphing engine, not a GIF) can live in three places:

  • Messages — every assistant reply carries it; the empty-state hero follows your cursor.
  • Cursor — enable in Settings and it trails your mouse across all screens with spring physics, eyes tracking the pointer, and a click-pop reaction.
  • System window — the same buddy in a click-through always-on-top window. It hides whenever Hive hides.

Recolor it anytime: Settings → Buddy Color (Orange, Ink, Ghost, Cobalt, Amber) applies to every avatar at once.

Notch & hotkeys

Press Ctrl + Shift + J anywhere — even with Hive minimized. A black pill pops at the top of your screen and springs open into the Buddy panel. The app itself never opens.

  • 🎙 mic — push-to-talk dictation straight into the box.
  • Type or speak — plain questions go to your buddy model.
  • Slash commands — see PC control.
  • Dismiss — Esc, click-away, or the ✕.
Why J? A bare Ctrl + Shift is modifiers-only and can't register as a global hotkey — J completes it.

PC control

The buddy acts on your machine through audited blocks. Destructive shell commands are refused by policy, and every action lands in the overlay log.

CommandDoes
/open <app|url>Launches apps (/open notepad) or URLs
/run <powershell>Runs a shell command, returns output
/click <x> <y>Moves the real cursor and left-clicks (DPI-aware)
/type <text>Types into the focused window

Plain questions work too: the model emits system_exec, buddy_click, and buddy_type blocks that execute in order, then speaks a short summary out loud.

Swarm & bots

Rail → Workers opens the roster in the main column, where chat lives. Each card shows avatar, role, and a Live badge for the active bot.

  • Chat live — starts a fresh conversation with that bot instantly.
  • New worker bot — name, role, avatar, system prompt. CEO Hive can never be deleted.
  • Conversations — the left panel stores one transcript per chat, restored on boot, switched with a slide animation.

Website accounts

The site runs email sign-in on Supabase. New accounts start pending; an admin flips them to approved (or denied) in the Supabase table editor. Each member gets a sequential customer number (#1, #2, …) shown in their profile panel, where they can also rename themselves, toggle email updates, and sign out.

Self-host note. The anon key in the page is publishable by design; row-level security restricts every member to their own row. Never expose the service_role key.

Modes

You never pick a raw model name. Four modes:

ModeUse it when
FastQuick answers, lowest wait.
AutoDefault. Hive balances speed and quality.
HeavyHarder questions, more analysis.
MaxDeepest pass. Slowest, most thorough.

Cloud computer

The right-side panel is a live view of HiveBox — a Cloudflare Durable Object that keeps a tiny disk, logs, and concurrent Scout / Hive / Pulse jobs. Toggle the canvas / panel button in the title bar. Commands on Cloudflare are limited to ls, cat, echo, pwd, uname.

Set HIVE_CLOUD_URL and HIVE_CLOUD_TOKEN in the desktop .env after deploying the worker.

Feedback

The Feedback button in the title bar sends a review to the website admin panel. Admins open admin.html to approve waitlist members and feedback.

FAQ

Windows only?

Yes, today — the buddy's click/type engine is Windows-native.

Is it free?

Yes. Bring your own OpenRouter key; free-tier models work out of the box.

Where is my data?

On your machine: chats and settings in local storage. The website keeps only auth + profile rows in Supabase.

Voice calling?

Coming soon. Dictation, spoken answers, and Telegram messaging work now.

The buddy vanished!

It hides with the app by design — show Hive and it returns. Behind fullscreen games, the OS compositor wins; it comes back after.
