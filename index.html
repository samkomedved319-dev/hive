Meet the Buddy. It lives at your cursor.

Enable it in Settings and an orange companion trails your mouse across every screen — breathing, blinking, watching. It pops an island when it listens, thinks, clicks, or types, and hides the moment you hide Hive. Summon the notch anywhere with Ctrl+Shift+J.

Quickstart

Clone the repo, npm install, npm run dev for daily use or npm run dist:win for the installer. Add your OpenRouter key in Settings → Models. Done.

🟠

Buddy

Settings → General → Hive Buddy at Cursor. The orange companion trails your mouse on every screen and hides whenever Hive hides. Pick its model and ink in the same place.

⬛

Notch

Press Ctrl+Shift+J anywhere: a pill pops at the top of your screen and expands into the Buddy panel. Ask, dictate with 🎙, or run /open /run /click x y /type. Esc dismisses.

🖱️

PC control

The buddy opens apps and URLs, runs PowerShell, clicks window coordinates, and types into the focused window. Destructive shell commands are blocked by policy; every action lands in the overlay audit log.

👑

Swarm

Rail → Workers opens the roster in the main view. Chat live with any bot, create custom workers, remove the ones you outgrew. Chats persist per conversation in the sidebar.
